# Blink

> **Under development.** Blink is not yet stable or feature-complete.

A macOS menu bar app that nudges you to take breaks and look away from your screens.

![Break overlay](docs/images/break-overlay.png)
![Menu](docs/images/menu.png)

## Building

```sh
swift build
```

## Packaging as a menu bar app

```sh
scripts/package-app.sh
open dist/Blink.app
```
